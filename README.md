## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/MrSalman394/salman-portfolio.git

# Navigate to project directory
cd salman-portfolio

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```

---

## 🌐 Deploy to Vercel (1-Click)

1. Push this repository to your GitHub account (`https://github.com/MrSalman394/salman-portfolio`).
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New Project"** and select `salman-portfolio`.
4. Vercel will automatically detect **Vite** settings (`npm run build` & `dist` output).
5. Click **"Deploy"**! 🚀
